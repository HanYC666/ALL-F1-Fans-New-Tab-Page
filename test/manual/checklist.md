# Manual Chrome checklist

- Load `dist/` as an unpacked extension in a clean Chrome profile.
- Open a New Tab offline and confirm the shell, search field, widgets, settings,
  and no console errors.
- Search with empty, Unicode, punctuation, and normal queries.
- Add/edit/remove/reorder shortcuts and verify unsafe schemes are rejected.
- Change opacity, blur, radius, accent, visibility, density, lock, reset,
  export, import, and delete data.
- Verify fresh/stale/offline F1 states and local/UTC time display.
- Verify background modes, uploads, invalid/large image errors, metadata,
  deletion, and object URL cleanup.
- Verify keyboard widget movement, focus styles, reduced motion, and 200% zoom.
- Configure a deployed YouTube proxy and verify results link to YouTube without
  exposing a key.
