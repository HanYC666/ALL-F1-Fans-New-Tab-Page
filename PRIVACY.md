# Privacy notice

This is the current privacy note for the development version. It still needs the real contact details and public URL before the extension is submitted to the Chrome Web Store.

## What stays on the device

The extension saves settings, shortcuts, cached F1 responses, and uploaded background images in the browser. It does not have accounts, analytics, advertising, or cloud sync.

## Websites the extension uses

Schedule and standings requests go to the public F1 data provider used by the extension. In direct YouTube mode, the browser opens YouTube's own search page. YouTube handles its own cookies and privacy settings; the extension does not copy or inspect them.

If the optional YouTube proxy is deployed, it receives the selected race/session search and normal request information such as an IP address from the hosting provider. The person deploying it must decide how long logs are kept and add that information here.
